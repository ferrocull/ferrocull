# Photo Mechanic vocabulary and keyboard shortcuts

Ferrocull is positioned as the FOSS Photo Mechanic. We commit to matching Photo Mechanic's keyboard shortcuts and user-facing vocabulary (see `CONTEXT.md`) wherever a term or shortcut is shared — `T` for tag, `Shift+1..5` for ratings, `X` for reject, `G` for promote, "ingest" rather than "download/import", "tagged" rather than "picked", and so on.

The cost is alienating users coming from other tools (Lightroom, darktable, digiKam) who expect different conventions. The benefit is that the target audience — PM users frustrated by its proprietary cost and macOS-only history — can pick up Ferrocull without retraining muscle memory. That's the FOSS-Photo-Mechanic value proposition; without it, Ferrocull is just another viewer.

This decision constrains every future UX choice: new features adopt PM's terminology and shortcuts first, and only invent new ones when PM has no equivalent.
